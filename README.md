# vocabulario-api

This repository contains the source code for [vocabular.io](https://vocabular.io) API

For additional information see [vocabulario-web](https://github.com/vanzay/vocabulario-web)

For service description read the [Help](https://vocabular.io/help) page

## Run locally

```sh
# build project
gradlew build

# start the server
gradlew bootRun
```
